# Alumni Networking Portal

Alumni Networking Portal is a web-based application developed using Django to connect students and alumni.  
It helps students get career guidance, job and internship opportunities, and enables alumni to mentor students.

## Features
- Student & Alumni Registration and Login
- Profile Management
- Job and Internship Posting
- Alumni–Student Communication
- Secure Authentication

## Technologies Used
- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite / MySQL

## Project Status
This project is under development.
